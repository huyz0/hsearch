# M01.06 impact CI acceptance

The [impact CI contract](../impact-ci.md) describes the conservative Cargo/non-Cargo planner, exact-head and graph binding, conditional native/reusable jobs and always-run final gate. Both native architectures retain all-feature debug/release/doctest checks and the current production coverage floor for their selected production dependency scope. Shared or uncertain changes select the full Rust and sandbox matrix. Read-only permissions, ephemeral runners and no persisted checkout token keep release credentials out of PR jobs.

Local qualification ran in the integrated M01.02 resource-leased image: UID10001, two CPUs, 4 GiB with swap0, 512 PIDs, bounded cache/target/duration. A [fresh cold smoke](m01-06-linux-smoke.txt) passed the complete Rust workspace/plan/model suite and 50 Python cases without Linux skips, including actual temporary Git history plus real offline Cargo metadata for docs-only/transitive/rename/deletion/missing-base controls. Both real RustFS stores passed TLS/auth/S3 probes and private namespace/cleanup isolation. The final ownership-policy counterexample and all prior cases then passed [51 Linux Python cases](m01-06-python-final.txt), planning/model controls and exact-container/lease cleanup under the same finite caps. No product Rust source changed.

Pure counterexamples cover every selected job missing, cancelled, failed or skipped; failed planning; a missing architecture; absent full-matrix sandbox work; weakened feature/profile or coverage scopes; malformed/unknown/truncated changes; missing graph/base; and stale checked heads. A missing graph/base deliberately produces a full plan. An invalid policy or failed planner makes `ci-ok` fail. Coverage scopes preserve per-file/per-crate 90% checks; generic missing-instrumentation/changed-line/profile-merge qualification remains M01.07.

Checksum-verified official actionlint1.7.12 passed both workflow files with shellcheck/pyflakes integrations disabled because those optional host tools are unavailable. Archive SHA256 was `6e7241b51e6817ea6a047693d8e6fed13b31819c9a0dd6c5a726e1592d22f6e9`. It was downloaded only into the delivery workspace, not added to the repository or installed globally. A cold, network-disabled, non-root container also successfully read the actual workspace's complete no-deps Cargo metadata.

Independent final-tree reviews, hosted full native workflow, observed hosted docs-only selection, and an observed main-branch `ci-ok` requirement remain acceptance work. No merge or delivery claim follows from the current targeted controls alone. M01.03-M01.05/M01.07-M01.08 and all runtime qualification remain in their original owning tasks.

The restricted Windows host run encountered denied redirected temporary-directory writes; those paths were not inspected or retried. The supported resource-leased Linux path supplied the complete passing suite. No tests were weakened.
