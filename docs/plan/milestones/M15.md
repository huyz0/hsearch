# M15: Cloud storage and KMS provider qualification

Generated from `tasks.json`; edit the ledger and run `python docs/plan/tools/plan.py render`.

Status: **planned**. Owner role: cloud/security.

## Goal

Extend real RustFS behavior to S3, GCS and Azure with their own measured semantics and keys.

## Completion prerequisites

M11, M12, M14

Task-level dependencies determine when individual tasks can start. Milestone prerequisites gate completion.

## Definition of done

- Actual S3, GCS and Azure backends pass the required conformance/race/recovery suites; no emulator-only result certifies them.
- Actual AWS/GCP/Azure key providers pass wrap/unwrap/version/permission/rotation/revocation tests with workload identity.
- Cross-provider copy/CCR restores independently and records residency/egress/key policy and provider-specific limits.
- Provider cost profiles use actual regional/path/SKU/byte-unit rates and usage/billing reconciliation; provider-specific transfer exemptions are validated.

### M15.04: Qualify cross-provider transfer and DR

Status: **planned**. Owner role: cloud/security.

Depends on: M15.01, M15.02, M15.03, M11.06.

### M15.06: Qualify cost, latency and reliability Pareto curves

Status: **planned**. Owner role: cost/architecture/operations.

Goal: Compare complete supported profiles at matched workload scope rather than advertise one cheapest bill.

Depends on: M07.07, M09.08, M13, M14, M15.04.

Deliverables:

- Sparse/busy/skewed idle/cold/warm/overload/recovery profile matrix, raw operation/byte counts and total-cost inventory
- Batch/pack/cohort/cache/refresh/zone/compaction/replication sweeps with dominated choices identified

Validation:

- Run matched logical correctness/security histories and each selected failure envelope, including zone loss, rebuild, catch-up, copy/CCR and key rotation
- Use rate snapshots plus actual compute/disk/cache inventory; include KMS, retries, page writes, network services and recovery debt
- Measure implemented multi-worker scale/cost curves against M02.05 thresholds; provider results support but do not replace M17.03 full-service G06 qualification

Definition of done:

- Every advertised profile meets its own frozen constraints or stays blocked; weakened semantics are explicit in comparisons
- Savings cannot come from omitted metadata, unknown rates, free cache assumptions, test skips or reduced replica guarantees under the same label
