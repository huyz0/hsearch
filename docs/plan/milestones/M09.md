# M09: Low-latency quorum journal module

Generated from `tasks.json`; edit the ledger and run `python docs/plan/tools/plan.py render`.

Status: **planned**. Owner role: journal/consistency.

## Goal

Deliver majority-fsync writes with independent fresh serving replicas and a bounded object archive backlog.

## Completion prerequisites

M07, M08

Task-level dependencies determine when individual tasks can start. Milestone prerequisites gate completion.

## Definition of done

- Three-zone persistent quorum mode survives one voter/zone loss without acknowledged mutation loss and never serves speculative state.
- Logical shards share bounded physical groups, with durable membership/snapshot/activation and no authority conflict with object mode.
- Archive/recovery/retention have independent checkpoints and admission stops before unarchived history exhausts disk.
- HA versus optional zonal quorum failure profiles and cross-zone replication bytes are explicit; budget pressure cannot weaken quorum or archive hard limits.
