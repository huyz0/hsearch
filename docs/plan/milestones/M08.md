Generated from `tasks.json`; edit the ledger and run `python docs/plan/tools/plan.py render`.

## Goal

Make the actual state of the system inspectable without secrets or uncontrolled diagnostic cost.

## Completion prerequisites

M07

Task-level dependencies determine when individual tasks can start. Milestone prerequisites gate completion.

## Definition of done

- Traces/logs/metrics correlate requests to shard/checkpoint/resource state with bounded cardinality and producer redaction.
- Versioned diagnostic API/CLI and optional MCP expose scoped, paginated read-only summaries and artifact handles.
- AI-only diagnostic exercises identify injected failures using operator-visible evidence; stalled telemetry does not stall search.
- Cost diagnostics separate logical operations, provider attempts, directed bytes, rate provenance and budget/maintenance debt with bounded cardinality.
