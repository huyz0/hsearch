# M08: Telemetry and AI-readable diagnostics

Generated from `tasks.json`; edit the ledger and run `python docs/plan/tools/plan.py render`.

Status: **planned**. Owner role: operations.

## Goal

Make the actual state of the system inspectable without secrets or uncontrolled diagnostic cost.

## Completion prerequisites

M07

Task-level dependencies determine when individual tasks can start. Milestone prerequisites gate completion.

## Definition of done

- Traces/logs/metrics correlate requests to shard/checkpoint/resource state with bounded cardinality and producer redaction.
- Versioned diagnostic API/CLI and optional MCP expose scoped, paginated read-only summaries and artifact handles.
- AI-only diagnostic exercises identify injected failures using operator-visible evidence; stalled telemetry does not stall search.
- Cost diagnostics separate logical operations, provider attempts, directed bytes, rate provenance and budget/maintenance debt with bounded cardinality.

### M08.01: Define observability and error schemas

### M08.02: Instrument all critical stages

Status: **planned**. Owner role: operations.

Goal: Make latency, resource and durability gaps attributable.

Depends on: M08.01, M07, M03.07.

Deliverables:

Validation:

Definition of done:

### M08.03: Implement diagnostic API and CLI

Status: **planned**. Owner role: operations.

Goal: Expose bounded scoped machine-readable state.

Depends on: M08.02.

Deliverables:

- Health/capabilities/shard/resource/retention/query/job diagnostics with pagination and snapshot generation
- Profile/rate provenance, retry-attempt/traffic cost attribution and budget/maintenance-debt explain endpoints.

Validation:

- Cross-tenant denial, output/time limits, truncation/cursor behavior and stale snapshot tests.

Definition of done:

- Responses have provenance/build/schema IDs and cannot execute shell/code or expose keys.

### M08.04: Provide MCP facade and incident bundles

Depends on: M08.03.

### M08.05: Build AI incident evaluation corpus

Status: **planned**. Owner role: operations.

Goal: Evaluate diagnosis quality with real failures.

Depends on: M08.04.

Definition of done:

- All critical scenarios identify actual cause and safe next action without cross-tenant disclosure.
