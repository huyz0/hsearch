## Goal

Create a reproducible Rust workspace and a measured, safe parallel-agent development loop before storage code grows.

## Completion prerequisites

M00

Task-level dependencies determine when individual tasks can start. Milestone prerequisites gate completion.

## Definition of done

- A fresh Linux x86_64/ARM checkout runs the same bounded validation interface locally and in CI, with pinned dependencies and >=90% production line coverage policy enforced.
- Two independent tasks build/review in isolated worktrees without resource/path/service interference; coordinator resumes after agent failure.
- CI selector and final-result controls are observed rejecting defects, cancellations, unknown changes and stale review evidence.
