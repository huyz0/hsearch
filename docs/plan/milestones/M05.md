### M05.03: Ratify encrypted block format

Status: **done**. Owner role: security/crypto.

Goal: Make portable authenticated random access safe.

Depends on: M05.02, M03.03.

Deliverables:

Fresh-key-per-object is a caller obligation; no object-store wiring (M05.04), no overlay format (M05.05), no ARM run.
