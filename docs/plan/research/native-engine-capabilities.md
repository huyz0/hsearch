## Remaining ports and measurable scope

M02.02 must implement bounded typed document/query adapters and strict declared core-v1 field parsing; final-source reference comparisons and held-out controls must run again. Authoritative latest GET, create/conflict/OCC, bulk framing/semantic isolation, generated ID resolution, hsearch receipts and PIT wire/lifetime semantics remain unimplemented, including all34 wire mutation steps. Existing reference goldens are retained. Their alternative is the declared bounded native receipt/identity/cursor profile, not a claim that native primitives implement HTTP semantics.

These experiments use at most128 physical documents,64 live IDs in the256-operation stress history,32 segments, eight fixed fields and three scheduled actors. They do not measure fleet throughput, native ordinal cardinality behavior at scale, persistent replay, provider costs or service p95. M02.02, M02.04, M02.10 and later placement/query/provider tasks retain their original independent qualification and limits.

Pinned source LICENSE/NOTICE and the prospective locked dependency graph were retained before import introduction. Index/search/analysis/codecs are dev dependencies for this research; production remains the existing Lucene-store boundary. No dependency source/binary or distribution notice bundle is vendored, and hsearch still has no selected redistribution license.
