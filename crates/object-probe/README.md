# Private object capability checker

This publish=false diagnostic package uses only std in normal/build code.
Its optional development-only local hsearch-object edge reuses the unchanged
public-trait oracle and unconditional-CAS negative; it is not a provider adapter.
No production crate may import this package. No SDK/external dependency or
redistribution license is introduced.

The library retains the original bounded version-one legal-history search and
adds version-two predeclared producer references, exact archive resolution,
restart/multipart models and six-area eligibility. The fixed executable reads
only authenticated `/probe-input` files and emits a small redacted report. It
has no network, compiler or lifecycle access. A failed/inconclusive required
scenario returns nonzero readiness.

The Python diagnostic transport/recorder executes the real pinned-image matrix;
the Rust checker uses independent operation/state/range oracles. Read
[the complete fixed profile](../../docs/plan/rustfs-probe-profile.md) for all
bounds, identity limitations, actual-image/source bindings, serial resources and
pending ordinary TaskStore/collector integration. Source and HOST fixture
results are not real provider results. All compiler/native/provider/coverage and
final review obligations must be reported from actual later qualification.
